# Bellows V1 Adoption Path

This document defines the canonical adoption path for Bellows V1.

Purpose:

Most creators are risk-averse about live tools.

Bellows adoption should therefore grow through confidence, not through forced full replacement on day one.

## Step 1: Record-Only Mode

Use Bellows purely for remote recording.

Properties:

- no broadcast risk
- lowest-friction trust entry point
- emphasizes recording reliability first

## Step 2: Hybrid Mode

Record in Bellows while streaming elsewhere.

Properties:

- Bellows proves capture quality
- creators preserve existing broadcast habits
- confidence builds without forcing full workflow replacement

## Step 3: Full Live Mode

Bellows replaces OBS, Riverside, or equivalent studio tooling entirely.

Properties:

- Bellows handles recording and live broadcast together
- operator trust has already been earned through lower-risk use
- full workflow simplification becomes credible

## Adoption Principle

Trust grows from successful low-risk experiences.
