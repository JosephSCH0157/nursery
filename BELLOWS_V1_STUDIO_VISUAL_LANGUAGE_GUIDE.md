# Bellows V1 Studio Visual Language Guide

This document defines the canonical visual language for Bellows V1.

Purpose:

Bellows should look and feel like studio equipment rather than general-purpose software.

## Visual Tone

Bellows should feel:

- calm
- grounded
- highly legible
- low motion
- low novelty

## Avoid

Bellows should avoid:

- playful animations
- social UI tropes
- gamified elements
- excessive gradients
- decorative clutter

## Layout Philosophy

Bellows layout should prioritize:

- stable geometry over responsive novelty
- predictability over cleverness

The layout should feel dependable under pressure.

## Typography

Typography must remain readable at distance.

Hosts may be several feet from the screen, so clarity is more important than ornamental style.

## Color Usage

Color communicates state, not decoration.

Overuse reduces meaning.

State colors should therefore be reserved for:

- recording truth
- warning conditions
- safe-to-close certainty
- informational updates where needed
