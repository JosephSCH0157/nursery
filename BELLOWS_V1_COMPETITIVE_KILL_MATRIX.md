# Bellows V1 Competitive Kill Matrix

This document defines how Bellows replaces existing categories of tools.

Purpose:

This is product strategy, not marketing copy.

Bellows does not compete by matching every feature of every incumbent tool.

Bellows competes by removing the specific weaknesses that make existing workflows fragile, intimidating, or fragmented.

## OBS

### OBS Strengths

- powerful
- flexible
- free
- broadcast capable

### OBS Weaknesses Bellows Targets

- intimidating setup
- scene complexity
- fragile configuration
- no built-in remote capture
- no local multitrack recording for guests
- requires technical skill

### Bellows Advantage

- studio workflow without production-software complexity
- remote recording as a native capability
- automatic capture safety
- no scene graph required for baseline use

## Riverside / StreamYard / SquadCast

### Their Strengths

- browser-based remote recording
- local-recording concept
- simple guest join

### Weaknesses Bellows Targets

- uncertain data safety perception
- limited production control
- fragmented workflow
- weak live-show integration
- editing disconnected from recording
- pricing friction

### Bellows Advantage

- integrated Forge pipeline
- deterministic output
- unified broadcast and capture model
- stronger failure recovery
- direct post-production integration

## Zoom / Meet / Teams

### Their Strengths

- ubiquitous
- familiar
- reliable conferencing

### Their Weaknesses For Production

- not designed as production tools
- compressed recording output
- mixed or weak source separation
- poor editing output
- limited broadcast capability

### Bellows Advantage

- purpose-built for shows
- professional capture output
- multitrack recording
- studio-focused UX

## StreamLabs / vMix / Pro Tools Remote And Similar Pro Tools

### Their Strengths

- powerful for professionals

### Their Weaknesses

- complex
- expensive
- hardware-heavy

### Bellows Advantage

- professional results without professional-operator complexity
- cloud-native workflow
- creator-friendly operational model

## Category Position

Bellows is not competing in only one category.

It spans:

- remote recording
- live production
- broadcast capture

Most existing tools do only one of these well.

## The True Kill Shot

Bellows integrates with:

- Anvil for script context
- Hammer for editing
- Tongs for storage and lifecycle
- Quench for publishing

Most competitors stop at recording.

Bellows is an end-to-end production pipeline rather than a single-stage tool.

## Strategic Principle

Bellows wins by making reliable remote production feel simpler, safer, and more integrated than the incumbent stack.
