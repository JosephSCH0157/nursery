# Bellows V1 Operator Promise And Guarantees

This document defines the covenant between Bellows and the creator.

Purpose:

State, in plain human terms:

- what Bellows will always protect
- what Bellows will never pretend to do

This document should survive marketing rewrites, redesigns, and leadership changes.

If Bellows violates these guarantees, users will feel betrayed rather than merely inconvenienced.

## Core Operator Promise

If your internet collapses, your computer crashes, or your guest disappears, your recording should still exist.

Everything else is secondary.

## Guarantee 1: Your Recording Is The Priority

Bellows exists to capture the session safely.

It does not primarily exist to:

- look flashy
- chase engagement
- multitask for its own sake
- entertain

If forced to choose, Bellows sacrifices features to protect the recording.

## Guarantee 2: Local-First Safety

Each participant machine records its own track locally.

This means:

- quality is not limited by connection quality
- dropouts do not erase content
- upload failure does not destroy the take

## Guarantee 3: Internet Is Transport, Not Storage

Bellows treats the network as a delivery path, not as a single point of failure.

If the connection dies:

- recording continues locally
- upload resumes later
- nothing is discarded by default

## Guarantee 4: Host Authority

The Host controls:

- session start
- session stop
- participant admission
- recording state

Guests cannot accidentally end or ruin the session.

## Guarantee 5: Guests Are Not Technicians

Guests should only need to:

- open a link
- approve permissions
- speak

No installs.
No accounts.
No configuration burden.

## Guarantee 6: Private By Default

Sessions are assumed confidential.

Bellows does not:

- publish automatically
- expose content publicly by default
- reuse recordings without intent

Ownership remains with the creator.

## Guarantee 7: Bellows Records Reality

Bellows captures what happened.

It does not:

- auto-edit
- beautify
- filter
- rewrite
- enhance beyond capture integrity

Post-production belongs downstream.

## Guarantee 8: Failure Should Be Contained, Not Catastrophic

When problems occur, Bellows prioritizes:

- preserving data
- maintaining clarity
- avoiding panic-inducing UI
- offering recovery paths

## Guarantee 9: Safe To Leave Means Safe

When Bellows indicates upload complete and safe to leave, that means:

- all local recordings are secured
- data exists redundantly where Bellows says it does
- the session can be closed without loss

No guesswork is allowed behind this promise.

## Guarantee 10: Resilience Over Perfection

Bellows prefers:

- a complete imperfect recording

over:

- a flawless partial recording

Missed frames are acceptable.
Lost sessions are not.

## Guarantee 11: No Hidden Critical Dependencies

Bellows will not quietly depend on:

- one cloud provider
- one browser feature
- one platform
- one service

If a dependency becomes unavailable, Bellows should degrade gracefully.

## Guarantee 12: Professional Predictability

Bellows behaves like equipment:

- stable
- consistent
- understandable
- repeatable

Bellows must not behave like experimental software.

## Guarantee 13: You Own The Content

Creators retain control of:

- recordings
- distribution
- editing
- deletion

Bellows is a capture tool, not a gatekeeper.

## Guarantee 14: No Surprise Publishing

Bellows will never:

- upload publicly without intent
- share links automatically
- distribute content by default

Nothing leaves the creator's control without an explicit action.

## Guarantee 15: Calm Under Pressure

During live recording, Bellows avoids:

- disruptive popups
- unnecessary alerts
- UI reflow
- feature distractions

Live mode prioritizes composure.

## Guarantee 16: Honest Status Reporting

Bellows clearly indicates:

- recording state
- connection state
- upload state
- participant state

Bellows does not depend on hidden background assumptions in place of visible truth.

## What Bellows Does Not Promise

Bellows does not promise:

- studio-grade lighting
- cinematic production
- automatic audience growth
- editing automation
- viral success
- perfect network conditions

It promises capture integrity, nothing more and nothing less.

## Canonical Bellows Promise

Bellows guarantees that your session is captured safely, even when everything else goes wrong.
